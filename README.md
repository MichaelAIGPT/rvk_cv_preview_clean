## 📌 О проекте

**RVK Safety CV** — отечественная масштабируемая программная платформа компьютерного зрения корпоративного уровня, разработанная для непрерывного автоматического контроля соблюдения правил охраны труда, промышленной безопасности и мониторинга ношения средств индивидуальной защиты (СИЗ) на технологических объектах водоснабжения и водоотведения:
- **Цеха механического обезвоживания осадка (ЦМОО)** — центрифуги, декантеры, шнековые прессы;
- **Насосные станции первого и второго подъемов, машинные залы ГНС** — мониторинг вращающихся насосных агрегатов, электродвигателей и высоковольтных шкафов;
- **Осадкоуплотнители, первичные и вторичные радиальные отстойники** — открытые водные поверхности и опасные перепады высот;
- **Транспортные галереи кека и конвейерные линии** — зоны повышенной травмоопасности движущихся лент;
- **Гаражи спецтехники и боксы аварийно-восстановительных машин (АВМ)** — контроль зон маневрирования крупногабаритного транспорта.

Система функционирует в режиме 24/7, обрабатывает RTSP-видеопотоки высокого разрешения (Full HD / 4K), непрерывно сопровождает персонал трекером с постоянным ID, осуществляет анатомический контроль СИЗ, фиксирует опасные действия персонала и формирует юридически значимый реестр инцидентов с карточками расследования по международному стандарту **CAPA / 5 Почему (5 Whys)**.

## 🧠 Что такое SOTA (State-of-the-Art) в контексте платформы?

Аббревиатура **SOTA (State of the Art)** в области Computer Science и искусственного интеллекта означает **«наивысший достигнутый уровень развития технологий на сегодняшний день»** — то есть наиболее эффективное, точное и надежное научно-инженерное решение в своем классе.

### Почему этот термин применен в RVK Safety CV v3.3?
В большинстве стандартных систем видеоаналитики применяется **одностадийный детектор** (Single-Stage), который пытается одной легкой нейросетью «в лоб» обнаружить человека и мелкую каску на всем пространстве кадра 1920×1080. В условиях реального цеха водоканала с плотным нагромождением технологического оборудования (фланцы труб, округлые кожухи электродвигателей, манометры, запорная арматура) одностадийная сеть неизбежно путает металлические детали оборудования с человеческими касками, генерируя десятки ложных тревог в смену.

В платформе **RVK Safety CV v3.3** реализован мировой индустриальный стандарт надежности — **каскадная архитектура (Cascade Human Pose & Anatomy Verification)**:
1. Силуэт человека первично изолируется детектором людей.
2. Нейросеть анатомических поз (Pose Estimation) определяет 17 ключевых точек скелета и вычисляет координаты головы, шеи и плечевого пояса независимо от наклона тела.
3. Классификатор сверхвысокого разрешения (EfficientNet-B0) анализирует строго целевую область головы, исключая фоновый шум оборудования.
4. Контур активного обучения (Active Learning) с банком **Hard Negatives** (специально собранных эталонов сложных труб и насосов цеха) гарантирует подавление ложных тревог.

### Ключевые преимущества архитектуры:
1. **Анатомическая надежность:** Классификатор касок вызывается строго на фрагменте головы, найденном по плечам и шее рабочего, а не по случайным предметам в цехе.
2. **Высокая вычислительная энергоэффективность:** Благодаря связке с трекером ByteTrack классификатор верхнего уровня опрашивается не на каждом кадре для каждого человека, а с адаптивным интервалом (1–2 раза в секунду), что снижает общую нагрузку на сервер на 75–80%.
3. **Два профиля развертывания:**
   - **GPU SOTA (EfficientNet-B0):** Максимальная точность для серверов с графическими ускорителями NVIDIA. Задержка конвейера: **9.8 мс**.
   - **CPU Edge (MobileNetV3):** Облегченный контур для стандартных серверных процессоров Intel Xeon / AMD EPYC без дискретной видеокарты. Задержка: **8.2 мс**.

### 1. Операционный диспетчерский центр (Operations Console)
- **Видеопоток реального времени:** MJPEG-стриминг сверхнизкой задержки с динамическим наложением векторной графики детекций (HUD);
- **Интерактивное управление просмотром:**
  - Плавный аппаратный цифровой зум колесиком мыши (от 50% до 300%);
  - Режим свободного перемещения по кадру (Pan / Drag) при приближении;
  - Полноэкранный режим с максимальным фокусом на видеоряде («⛶ На весь экран»);
  - Покадровая навигация вперед и назад (⏮️ / ⏭️) для детального разбора спорных моментов;
  - Регулировка скорости воспроизведения (0.5x замедленный, 1x стандартный, 2x, 4x ускоренный просмотр);
- **Мультикамерный мониторинг:** Быстрое переключение между технологическими постами (Камеры 1–5) с живыми превью-каналами.

### 2. Панель оперативного управления модулями ТБ
Быстрые независимые тумблеры на панели инструментов позволяют оператору включать и выключать требуемые детекторы в реальном времени:
- `⛑️ Каски` — контроль наличия защитных касок на голове персонала;
- `🦺 Жилеты` — контроль ношения сигнальной спецодежды со световозвращающими полосами;
- `🚬 Курение` — обнаружение открытого тления и специфического жеста поднесения руки ко рту;
- `📱 Смартфон` — фиксация разговоров по телефону и набора сообщений в опасной близости от работающих механизмов;
- `⚠️ Опасные зоны` — подсветка полигонов оборудования и контроль опасного сближения;
- `🧩 Маска силуэта` — попиксельная сегментация тела человека (YOLOv8-Seg) для уверенной работы в условиях сложного фона цеха;
- `🔥 Пожар и задымление` — детектор открытого пламени и первичных признаков задымления.

### 3. Интерактивный редактор опасных технологических зон
- Инструмент векторного рисования полигональных зон произвольной конфигурации прямо поверх живого видеокадра камеры;
- Классификация зон по степени риска: *«Критическая опасность»*, *«Зона вращающихся валов и насосов»*, *«Зона обслуживания электроустановок»*;
- Индивидуальная настройка допустимого времени нахождения (Dwell Time Threshold) и обязательных требований СИЗ для допуска в зону.

### 4. Юридический журнал инцидентов и модуль CAPA (5 Почему)
- **Промышленная фильтрация спама:**
  - *Фильтр дребезга (Debounce 3+ кадра):* Случайные кратковременные смазывания или повороты головы отфильтровываются и не тревожат оператора;
  - *Кулдаун дедупликации (15–30 секунд):* Непрерывное нахождение нарушителя в поле зрения генерирует строго одну карточку события с привязкой к его треку, а не сотни одинаковых оповещений;
- **Двухэтапная верификация оператором:** Маркировка карточки статусами *«Подтверждено»* или *«Ложное срабатывание»*;
- **Мгновенный переход:** Кнопка **`▶ В плеер`** осуществляет точный покадровый переход видеоплеера непосредственно к моменту фиксации нарушения;
- **Карточка расследования CAPA (Corrective and Preventive Action):**
  - Структурированный разбор инцидента по методике **«5 Почему» (5 Whys)** для выявления коренной причины (Root Cause);
  - Назначение корректирующих мероприятий, ответственного лица и контрольного срока устранения;
- **Экспорт отчетности в один клик:**
  - **Excel (.xlsx)** — официальный отчет для инспекции по охране труда и руководства филиала;
  - **CSV** — структурированный массив для автоматического импорта в корпоративную систему 1C:ERP / ТОиР;
  - **SCADA Telemetry (OPC UA)** — передача сигналов тревог в АСУ ТП цеха.

### 5. AI Лаборатория и контур активного обучения (Active Learning MLOps)
- **Банк кропов (`/dataset`):** Каталог вырезок силуэтов и голов с удобной фильтрацией (*«Все»*, *«В каске»*, *«Без каски»*, *«Оборудование / Hard Negatives»*) и сортировкой;
- **Экспресс-разметчик FastTagger (`/tagger`):** Эргономичный интерфейс верификации с поддержкой горячих клавиш (`1` — Каска, `2` — Без каски, `3` — Ложное/Оборудование) со скоростью до 200 образцов в минуту;
- **Модуль фонового дообучения:** Запуск обучения модели на накопленных образцах предприятия в один клик прямо из браузера (с автоматическим сохранением лучших весов `best.pt`);
- **Центр переключения моделей:** Мгновенная смена весов в конвейере без остановки сервера (SOTA V3, MobileNetV3 Edge для CPU, Baseline подрядчика);
- **Экспорт датасета:** Выгрузка верифицированных сэмплов в стандартный формат YOLO / PyTorch для дальнейших исследований.

### 6. Модуль бенчмаркинга и трекер прогресса (Run Progression Tracker)
- Фиксация результатов каждого контрольного прогона (`RUN-001`, `RUN-002`, `RUN-003`, ...);
- Автоматический расчет метрик: точность (Precision), полнота (Recall), F1-мера, количество ложных тревог;
- Наглядная таблица динамики улучшения: отображение дельты прироста точности к базовой модели подрядчика и к предыдущей итерации нашей системы.

### 7. Двухоконный A/B плеер сравнительного анализа
- Синхронное покадровое сопоставление работы моделей «бок о бок»: слева — базовая одностадийная сеть подрядчика (порт 18080), справа — трехстадийный каскад SOTA v3.3 (порт 8000).

### 8. Аналитический дашборд руководителя (Executive Safety Dashboard)
- Сводная инфографика и ключевые показатели эффективности (KPI) охраны труда;
- Распределение нарушений по сменам, дням недели и цехам;
- Тепловая карта распределения опасных инцидентов по зонам предприятия;
- Индекс безопасности технологического объекта (Safety Score) и тренд снижения травмоопасности.

### 9. Инженерная панель и системная диагностика
- Конфигурация порогов уверенности (Confidence thresholds), порога перекрытия NMS IoU, параметров трекера ByteTrack (длина трека, max age);
- Выбор вычислительного бэкенда (NVIDIA CUDA / TensorRT / OpenVINO / CPU) и управление числом потоков;
- Диагностический аудит-лог с возможностью скачивания архива системных журналов.

## ⚙️ Системные требования и расчет пропускной способности серверов (Sizing & Capacity)

### Архитектурная особенность оптимизации нагрузки в v3.3
Для обеспечения высокой масштабируемости на большом числе видеокамер в платформе реализован алгоритм **адаптивного опроса классификатора**:
1. Детектор людей (YOLOv8) обрабатывает кадры видеопотока с оптимальной частотой **10–12 FPS** (скорость передвижения персонала на объектах водоканала составляет 1–1.5 м/с, поэтому 10 кадров в секунду обеспечивают 100% покрытие без пропусков).
2. Трекер (ByteTrack) непрерывно удерживает траекторию человека.
3. Тяжелый классификатор EfficientNet вызывается не на каждом кадре для каждого человека, а **при первичном захвате трека и далее с периодичностью 2 раза в секунду** для подтверждения статуса СИЗ.
4. Это архитектурное решение снижает общую вычислительную нагрузку на 75–80%, позволяя подключать значительно больше камер на один сервер.

## 🚀 Установка и запуск

### Быстрый запуск в один клик (Windows)
Запустите командный файл:
```cmd
start.bat
```
Скрипт автоматически подготовит виртуальное окружение `.venv`, проверит зависимости и запустит платформу.

---

### Ручной запуск (Windows / Linux)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/MichaelAIGPT/rvk_cv_preview_clean.git
   cd rvk_cv_preview_clean
   ```

2. **Создайте и активируйте виртуальное окружение Python (рекомендуется Python 3.10 или 3.11):**
   - *Windows:*
     ```cmd
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - *Linux:*
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Запустите сервер платформы:**
   ```bash
   python backend/app.py
   ```

5. **Откройте веб-интерфейс в браузере:**
   ```
   http://localhost:8000/
   ```
   *(Интерактивная спецификация REST API Swagger доступна по адресу `http://localhost:8000/docs`)*
